📱 Pasim QuikFlex long iPhone

QuikFlex inap stap olsem app long Home Screen bilong yu.

  1. Opim QuikFlex long Safari.
  2. Pressim Share button.
  3. Pressim More sapos yu lukim dispela.
  4. Makim "Add to Home Screen".
  5. Pressim "Add".

Nau yu ken painim QuikFlex long Home Screen bilong yu.

📱 Pasim QuikFlex long Android

Sapos install i no wok, bihainim ol dispela step:

  1. Opim dispela website long Chrome.
  2. Pressim tripela dot ⋮ antap.
  3. Makim "Install app" o "Add to Home screen".
  4. Pressim "Install" o "Add".

Sapos yu daunlodenim app pinis, opim dispela file na bihainim tok bilong fon.

🔢 Detek QuikFlex bai ritim namba bilong card bilong yu.
📱 Topap Konfomim code na fon bilong yu bai mekim arapela.
